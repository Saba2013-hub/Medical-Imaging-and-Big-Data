# Diabetic Retinopathy Grading Using Deep Learning

## Project Overview

This project investigates automated diabetic retinopathy grading from retinal fundus photographs using deep learning and radiomics-based approaches.

The models were developed and evaluated using the APTOS 2019 dataset, with external evaluation performed on the IDRiD dataset to assess generalization across datasets.

## Repository Contents

- `notebooks/` — Jupyter notebooks containing the experimental workflow.
- `src/` — Python source code for preprocessing, model development, evaluation, and visualization.
- `splits/` — Dataset split definitions used in the experiments.
- `figures/` — Figures and visualizations generated during analysis.
- `tables/` — Experimental results and evaluation tables.
- `logs/` — Saved experiment logs.
- `report/` — Final project report.
- `presentation/` — Project presentation.

## Trained Model Files

**The trained model weights are not included in this repository because their file sizes exceed GitHub's standard upload limits.**

The project code, experimental methodology, evaluation results, and documentation are provided to support understanding and reproduction of the experiments.

Reproducing the trained models requires access to the original datasets, the necessary software dependencies, and the training procedures described in the notebooks and report.

## Datasets

The project uses two publicly available research datasets:

- **APTOS 2019:** Model development and internal evaluation.
- **IDRiD:** External evaluation.

The original retinal images are not redistributed in this repository. Users should obtain the datasets from their respective sources and comply with the applicable usage conditions.

## Academic Context

Developed as part of the Medical Imaging & Big Data coursework in the MSc Data Science programme at the University of Milano-Bicocca.
