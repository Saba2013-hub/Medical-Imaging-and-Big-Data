# Trained Models

This directory documents the trained models used in the diabetic retinopathy grading project.

The trained model weights are not included in this GitHub repository because they exceed GitHub's standard file-size limits.

The source code, notebooks, evaluation results, and experimental documentation are provided in the repository.

To reproduce the experiments, users will need to obtain the datasets and retrain the models using the documented procedures.

The original trained weights are maintained separately and are not publicly distributed through this repository.
